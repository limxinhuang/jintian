# 今天：产品与交互说明

状态：按用户确认的原型和后续修改实现，当前版本 0.5.1。

## 目标

- 同时最多五个未归档目标。
- 创建目标只填写名称和截止日期，开始时间自动记录为创建时刻，不让用户填写。
- 截止日期可选创建当天至四周后（0～28 天，含边界），不能早于今天，没有至少一周的限制。
- 日历顶部高对比色块显示今天的完整日期和星期；当天格子以加粗日期、2 dp 边框、底色和「今天」文字突出。选中日期以实心色块及「已选」区分，选中今天时仍显示「今天」。
- 日历提供「选择今天」，范围外日期置灰不可选；翻到下个月仍保留今天的顶部提示。确定后提交，取消不修改截止日。
- 兼容旧版已创建及 CSV 备份中的 29 天目标，保持原截止日，新目标不允许超过 28 天。
- 目标内全部步骤完成后可以归档，归档记录保留且不占五个名额。
- 刚创建、尚无任何步骤的空目标可以删除，删除前确认。
- 到期目标不自动删除或归档。

## 步骤

- 每个步骤必须是一天内能完成的一件事。
- 创建步骤选择单次型（默认）或循环型并填写内容，没有预计时长输入，也没有「是否一天内完成」选项。
- 未完成步骤分为「待执行」「下一个」「正在执行」，完成后保留记录。
- 新步骤默认排在待执行清单末尾。
- 待执行步骤呈现为卡片，可以直接长按整张卡片拖动排序；移动到列表边缘会滚动。没有上下箭头按钮。
- 读屏用户可以使用卡片的前移／后移无障碍操作。
- 初次排好顺序后点击「确认下一项」，队首成为锁定的下一项。
- 每个目标最多一个下一项；下一项只允许修正文字，不能删除或调整顺序。

### 循环型

- 每次进入下一项时，在待执行队尾自动追加一个同循环的新步骤，使用独立步骤 ID；手动确认与自动补位均适用。
- 每个进行中的循环保留一个待执行副本。可同时有同系列的当前执行、下一项和一个待执行，待执行副本可拖动。
- 单次型不生成副本。旧版步骤默认单次型；创建后类型固定。
- 卡片显示「循环型 · 已完成 N 次」，次数取同一循环 ID 的完成记录数，不按名称合并。
- 「完成本次」记录时间并累计一次，继续保留后续步骤。
- 「完成并结束循环」需确认；计入本次完成，移除同系列的待执行与下一项，将所有历史记录标为循环已结束。其他循环和单次步骤不变。
- 结束循环是锁定下一项不可删除规则的明确例外。若结束后下一项为空，可在详情确认其他待执行步骤。
- 尚未进入下一项的循环可以删除；已开始循环的副本需通过执行中的结束操作移除，避免单独删除导致循环中断。
- 编辑文字同步同系列待执行与下一项，不改写当前执行和历史记录。
- 重启、普通完成、JSON/CSV 恢复均不触发生成副本，统计每次完成均计为一步。

### 累计数值达标循环

- 创建时选择「循环型 → 累计数值达标」，额外填写目标数值与单位。原手动结束方式保留。
- 进入下一项仍然追加待执行副本；完成时必须输入本次增加的数值，不能把已有总量再次计入。
- 弹窗显示当前累计值、计入后累计值，达标时明确提示将结束循环并移除后续副本；取消不改数据。
- 累计达到或超过目标自动结束，保留实际增量、次数、开始／完成时间，不丢弃超额数值。
- 使用精确十进制计算；数值必须大于 0，最多 12 位整数、6 位小数。单位 1～12 个字。
- 卡片显示完成次数、累计值／目标数值及单位、进度条；历史卡片还显示本次完成量。进度条最多 100%，文字保留实际累计值。
- 创建后目标数值与单位固定，编辑保留只改文字的规则。累计型不提供提前手动结束按钮。
- 保存失败、重复确认、过期步骤 ID 均不会重复累计；统计按完成次数计步，不将不同单位混加。

## 执行流程

1. 全应用没有正在执行的步骤时，可以从任意目标的下一项开始。
2. 点击开始后，记录开始时刻；该目标待执行队首自动补位为下一项。
3. 全应用同时最多一个正在执行的步骤，所有下一项的开始按钮暂不可用。
4. 当前步骤显示具体开始时间和已持续时长，每秒更新。
5. 完成时记录结束时间和开始时间，进入完成记录，释放全局执行名额。
6. 接下来由用户主动选择任意目标的下一项，不自动开始。

应用退到后台、关闭或手机重启后，仍按原始开始时刻计算经过时间。持续时长包含后台经过的时间，不等同于有效工作时长。开始后超过 24 小时会提示，不会自动判定完成或丢弃记录。

## 首页与底部导航

底部两个入口：今天、统计。

今天页依次展示：

- 一天倒计时：今天剩余时分秒，以及今天已经过去的进度。
- 全应用唯一的正在执行步骤，带所属目标、开始时间、持续时长和完成按钮。
- 各目标的下一项，最多五个目标，保留目标名称与截止信息。

首页不展示待执行清单或完成清单。点击目标进入详情。编辑表单暂时隐藏底部导航，保存或取消后回到目标详情。

目标卡片保留「详情」入口，不再单独显示「进入目标安排任务」或「去归档」操作行。下一项为空时，仅显示对应状态。

## 一天倒计时

- 按手机当前时区的本地 00:00 到次日 00:00 计算。
- 每秒显示剩余时间；进度条填充表示已经过去的比例。
- 午夜自动归零开始新的一天，不改变目标或步骤状态。
- 回到前台重新读取系统时间，不依赖后台定时器递减。
- 支持时区变化及夏令时带来的不同自然日长度。

## 统计页

- 今日完成步骤数。
- 累计完成步骤数，包含已归档目标。
- 已完成并归档的目标数。
- 累计执行时长，包含已完成步骤与当前执行中的步骤。
- 最近七天每日完成数量。
- 每个目标的完成进度。
- 最近完成的步骤、所属目标、完成时间和用时。

日期按设备当前时区的完成时刻归组。旧版没有记录真实时间的已完成步骤只计入累计数量，不虚构执行时长或完成日期。

## 本地保存与范围

原生安卓应用，数据保存在手机应用私有目录，不需要账号或联网。

写入成功后才刷新界面；整个应用统一串行处理数据修改，连续点击不能产生多个执行中步骤。读取失败时保留原文件并提示重试，不用空数据覆盖。

### CSV 导入与导出

- 入口在「统计 → 数据备份」。
- 通过系统文件选择器选择导出位置或要导入的 CSV，无需存储权限。
- 一份 CSV 包含全部目标与步骤、顺序、状态和时间记录，包含空目标、已归档目标和执行中步骤。
- CSV v3 保存步骤类型、循环 ID、结束标记、累计目标、单位和每次完成数值；次数与累计值从历史记录恢复。兼容 v1 单次型和 v2 手动循环数据。
- 导入先校验格式、数量、顺序和应用规则，再显示预览。
- 预览明确提示整份替换当前数据；必须点击「替换并恢复」才写入，不合并。
- 空备份恢复前明确提示清空当前数据；取消或校验失败不改变数据。
- 文件缺失记录、重复 ID、超过五个未归档目标、存在多个执行中步骤等情况不允许导入。
- 恢复执行中步骤时保留原开始时间；统计由恢复数据重新计算。
- 可先导出当前数据，再导入其他备份。备份文件最大 10 MB。

首版包含目标管理、步骤拆分、卡片排序、下一项锁定、开始与完成、时间记录、一天倒计时、底部导航、统计、本地保存、归档和浅／深色适配。暂不包含账号、云同步、社交或消息提醒。
